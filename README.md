# 🧪 Automation Exercise — UI Test Automation Project

Проект по автоматизации UI-тестирования для учебной e-commerce платформы **Automation Exercise**. В проекте реализовано покрытие ключевых пользовательских сценариев (End-to-End, регистрация, авторизация, корзина и оформление заказа)

---

##  Объекты и цели тестирования

* **Тестируемый веб-сайт:** [Automation Exercise](https://automationexercise.com/)
* **Цель:** Проверка корректности работы критических бизнес-процессов интернет-магазина, стабильности UI-элементов и предотвращение регрессионных ошибок.

---

##  Технологический стек

* **Язык программирования:** Python 3.14+
* **Тестовый фреймворк:** Pytest
* **Инструмент автоматизации UI:**  Playwright
* **Генерация отчетов:** Pytest HTML
* **Управление зависимостями:** pip / requirements.txt

---


### Тест-кейсы

🧪 Тест-кейсы
- Регистрация и аккаунт
- Проверка успешной регистрации нового пользователя.
- Проверка сообщения ACCOUNT CREATED! после создания аккаунта.
- Проверка удаления созданного аккаунта.
- Проверка успешной авторизации зарегистрированного пользователя.
- Проверка отображения пользователя после авторизации.
- Проверка выхода из аккаунта.
- Проверка авторизации с некорректным email или паролем.
- Проверка страницы авторизации перед входом в аккаунт.
🛒 Корзина
- Добавление нескольких товаров в корзину.
- Проверка наличия добавленных товаров в корзине.
- Проверка цены товаров.
- Проверка количества каждого товара.
- Проверка итоговой стоимости товаров.
💳 Оформление заказа
- Авторизация пользователя перед оформлением заказа.
- Добавление товаров в корзину.
- Переход в корзину.
- Переход к оформлению заказа.
- Добавление комментария к заказу.
- Заполнение платёжной информации.
- Отправка заказа.
